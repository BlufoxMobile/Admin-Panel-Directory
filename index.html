GitHub Token Settings

This page reads and writes data/store-directory.json in the Daily-Sales-Report repo. The embedded token is used by default. Override only if you need a different account's token.

✉️ Email Team

Pick which groups to email, adjust the recipient list, write your message, then open it in Outlook. Everyone is placed on the BCC line so recipients can't see each other's address. Add any pictures or attachments in Outlook before you hit Send.

Pictures & attachments: click "Compose in Outlook" and add them there — Outlook opens pre-filled so you can drag in images or attach files before sending. For very large groups (like all reps), the addresses are copied to your clipboard so you can paste them into the BCC field.
